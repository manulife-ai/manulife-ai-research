This paper presents the design and implementation of a Retrieval Augmented Generation (RAG) system deployed in the call center of a large financial institution. The system enables call center agents to ask natural language questions and receive accurate answers sourced from both unstructured documents and structured databases.

**Key Contributions:**
- End-to-end RAG architecture handling both unstructured and structured data sources
- Practical deployment in a production call center environment
- Evaluation against real-world call center queries in the financial services domain
